# PRD and Functional Specs Rules

All Product Requirement Documents (PRDs) must follow the standard engineering SOP:
1. **Problem Statement & Target Audience**: User pain points, personas, and business motivation.
2. **Success Metrics**: Measurable KPIs (activation rate, retention, latency, throughput).
3. **User Stories & Workflows**: Clear user personas with motivation and acceptance criteria.
4. **Competitive Matrix**: Quadrant chart / analysis against benchmark solutions.
5. **Requirements Pool**: Categorized by priority (P0 Blocker, P1 Critical, P2 Nice-to-have).
6. **Technical Constraints & Security**: RLS requirements, rate limits, performance SLAs.
