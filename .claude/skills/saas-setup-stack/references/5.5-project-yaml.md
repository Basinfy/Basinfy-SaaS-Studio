# SaaS Stack Configuration Reference (project.yaml)

This reference documents the structure, commands, and fields required in `project.yaml`.

---

## 1. Minimal Working Configuration

```yaml
schema_version: "2.0"
product:
  name: "MySaaS"
  slug: "my-saas"
  tier: "b2b"

stack:
  frontend: "nextjs"
  backend: "fastapi"
  database: "postgresql"
  orm: "prisma"
  auth: "supabase"
  billing: "stripe"
  cloud: "vercel"

commands:
  build: "npm run build"
  test: "npm test"
  run: "npm run dev"
  lint: "npm run lint"
  smoke: "curl -f http://localhost:3000/api/health || exit 1"

modes:
  automation: "collaborative"
  rigor: "standard"
  review_mode: "lean"

docs:
  density: "balanced"
```

---

## 2. Standard Stack Definitions

### Next.js Fullstack (Default)
- **Frontend**: Next.js 15+ (App Router, React 19, TypeScript, Tailwind CSS)
- **Backend**: Next.js Route Handlers / Server Actions
- **Database**: PostgreSQL (Supabase / Neon) via Prisma ORM
- **Commands**:
  - `build`: `npm run build`
  - `test`: `npm test` (Vitest)
  - `run`: `npm run dev` (starts on port 3000)
  - `smoke`: `curl -s -f http://localhost:3000/api/health`

### Next.js + FastAPI (AI & Heavy Compute)
- **Frontend**: Next.js (port 3000)
- **Backend**: FastAPI (Python async, port 8000)
- **Database**: PostgreSQL via SQLAlchemy / Alembic
- **Commands**:
  - `build`: `npm run build && pip install -r requirements.txt`
  - `test`: `pytest && npm test`
  - `run`: `uvicorn main:app --reload --port 8000`
  - `smoke`: `curl -s -f http://localhost:8000/health`
